# 2026-11-08 修复：启动期 EULA 弹窗 No MaterialLocalizations 卡死

## 根因
- app.dart 的 _GrandBlueAppState.build 返回 MaterialApp，其 State.context 在 MaterialApp **外层**
- _onCompose 用该 context 调 EulaDialog.show → showDialog 向上找 Navigator/MaterialLocalizations 找不到（Navigator 在 MaterialApp 内部，是后代不是祖先）→ 未处理异常 → 启动即卡死 ANR

## 修复（最小改动，弹窗逻辑不变）
- app.dart：新增全局 `appNavigatorKey = GlobalKey<NavigatorState>()`，MaterialApp 注入 `navigatorKey: appNavigatorKey`
- eula_dialog.dart：show() 内部改用 `appNavigatorKey.currentContext ?? context`（未挂载防御：直接返回 false 不崩溃）；函数签名不变，调用点零改动

## 模拟器实测（Pixel 7 API 34）
- 启动不再 ANR；点「+」→「航海守则」弹窗正常弹出 → 点「同意并继续」正常关闭
- logcat：MaterialLocalizations / FATAL EXCEPTION 计数 = 0
- ⚠️ 环境坑（重要）：WorkBuddy 沙箱 shell 带 HTTP_PROXY=127.0.0.1:56591，会劫持 flutter run/test 的 vm-service WebSocket（"Invalid WebSocket upgrade request"假性崩溃）。绕过：`env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy flutter run ...`。flutter test 失败同根因
- adb 路径：E:/Program/Android/SDK/platform-tools（local.properties sdk.dir）

## 补充：同根因第二处修复（真机验证发现）
- 首轮模拟器验证发现：EULA 同意后 _onCompose 仍用根层 context 调 `Navigator.of(context).push(ComposerPage)` → "Navigator operation requested with a context that does not include a Navigator"，发帖页打不开（静默失败）；`ScaffoldMessenger.of(context)` 同隐患
